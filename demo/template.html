Use Nib in a project

Paste nib.js into the page once (a script tag or inline). It needs no internet and stores nothing.

<nib-pad id="answer" symbols="school" style="height:240px"></nib-pad>
<script>
  answer.addEventListener('change', e => {
    const r = e.detail;          // null when the pad is cleared
    if (r) console.log(r.latex); // "\frac{3}{4}x+2=11"
  });
  // answer.undo(); answer.clear(); answer.latex; answer.strokes
</script>
// Your own canvas or saved ink: strokes are arrays of [x, y] points
const r = Nib.recognize(strokes, { symbols: 'numbers' });
r.latex   // LaTeX for KaTeX/MathJax
r.text    // "3/4x+2=11"
r.lines   // one entry per written line
r.symbols // each symbol: label, box, candidates

Symbol sets: school (default), all, numbers, or a list such as ['0','1','2','x','+','='].
